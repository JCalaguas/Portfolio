My personal portfolio website. **Live site:** https://jcalaguas.github.io/Portfolio/

- Responsive from phone to desktop
- Animated face-landmark mesh in the hero, a nod to my drowsiness detection thesis

Built with AI coding agents, reviewed and tested by me.
